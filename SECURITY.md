# Security Policy

## Supported Versions

Only the latest release on `main` receives security updates.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately via [GitHub Security Advisories](https://github.com/sebastiendfortier/lume/security/advisories/new) rather than opening a public issue.

Include a clear description, steps to reproduce, and affected version/platform. We will acknowledge reports promptly and coordinate a fix before public disclosure.
